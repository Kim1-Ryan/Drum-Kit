#Adding event listeners with JavaScript:
The addEventListener() method attaches an event handler to a DOM element without overwriting existing event handlers.

##Basic formula: 
element.addEventListener(event, function);

###Eg. with parameters: 
element.addEventListener('click', function() {
    myFunction(param1, param2);
});

##Definition:
An `event` is a string representing the event type.

###Eg. mouse events (click, dblclick, mouseover, mouseout, mousedown) or keyboard events (keydown, keyup, keypress).
